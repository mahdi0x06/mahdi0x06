### 🧠 Featured AI & Machine Learning Projects

🔹 **[Oxford-IIIT Pet Transfer Learning](https://github.com/mahdi0x06/oxford-pet-transfer-learning)**  
Built an end-to-end **37-class image-classification pipeline** using a pretrained **ResNet18 in PyTorch**. Compared a frozen-backbone baseline with partial fine-tuning, used separate train/validation/test splits, and performed per-class evaluation and confusion-matrix analysis. The fine-tuned model achieved **87.84% test accuracy** and **87.69% macro F1-score**.

🔹 **[Artificial Intelligence — Algorithms from Scratch](https://github.com/mahdi0x06/Artificial_Intelligence)**  
Implemented a broad collection of classical AI and machine-learning methods, including **A\* search**, **Minimax with alpha-beta pruning**, a **CSP-based Nonogram solver**, Hidden Markov Models, Decision Trees and Random Forests from scratch, Value and Policy Iteration, **Q-Learning**, and **SARSA**.

🔹 **[CollarAI](https://github.com/mahdi0x06/Collar_AI)**  
Developed a Chrome extension for real-time body-language feedback during video calls using vision-capable AI APIs. The project includes live analysis, configurable privacy controls, local session management, and post-meeting reports with visual summaries.
